Set codes are the two-three character combinations that represent sets. For sets released after 2015, the three-character set code can be found in the lower left hand corner of a card.

How to make a card

  1. Frame — choose a frame group and a frame pack (or search one). With Auto load Frame group checked, the text, art and symbol placements are set up for you. Click a color, then Add Frame to Card. To make a two-color card, add a second color with Add Right Half to Card.
  2. Layers — every frame image you add becomes a layer. Drag layers to re-order them, click one to change its opacity, position, colors or masks, and use the × to remove it.
  3. Text — pick a text area (Title, Type, Rules, Power/Toughness...) and type. Mana symbols use codes like {w}, {2}, {t}. Use {flavor} to start the flavor text. The full list of codes is in the Text tab.
  4. Art — upload your image, then drag the card to move it (Shift + drag to scale, Ctrl + drag to rotate) or use Auto Fit Art. Credit the artist.
  5. Set Symbol — type a set code and pick a rarity, or upload your own symbol.
  6. Watermark — search or browse the watermark gallery, then choose colors and opacity.
  7. Collector — set the number, rarity, set, language and artist printed at the bottom of the card.
  8. Save — Save and Update Gallery keeps the card on this device, Download image exports a PNG (2010×2814, ready to print at 800 DPI).
Imports from Scryfall, card art by name and online set symbol sources need an internet connection. Everything else works offline.
